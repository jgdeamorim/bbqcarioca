4. Eu NÃO colocaria languages TEXT como JSON

Porque depois queremos perguntar:

ou:

ou:

13. Haversine: manter, mas corrigir o nome

19. O frontend React tem uma inconsistência

O documento fala:

React 19 + Vite SPA

mas usa:

useActionState()
useFormStatus()

Isso não significa automaticamente que teremos Server Actions.

Num SPA Vite, a arquitetura continua sendo:

React
 ↓
fetch
 ↓
Worker API

Então eu não usaria o conceito de "Action" como se fosse uma Server Action.

Pode ser simplesmente:

submitApplication()

que chama a API.

O useFormStatus pode ser usado dentro do ecossistema apropriado, mas não devemos misturar mentalmente Next.js Server Actions com uma SPA Vite + Worker API.

Essa parte merece revisão.
