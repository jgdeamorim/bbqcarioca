Mas existe uma diferença importante:

“BBQ caterer” = empresa/pessoa que fornece comida e serviço de catering.

“BBQ chef for hire” = pessoa contratada para cozinhar.

“Private chef” = conceito mais sofisticado/premium, mas pode afastar quem procura simplesmente churrasco para festa.

“Grill chef” = pode funcionar, mas é menos específico que BBQ.

“Pitmaster” = excelente palavra para autoridade no universo BBQ, mas não necessariamente é a primeira palavra que um cliente comum usaria para procurar o serviço.

5. Mas existe uma pegadinha importante

Eu não colocaria todas essas palavras como negativas automaticamente.

Por exemplo:

Brazilian steakhouse

pode parecer restaurante.

Mas uma pessoa procurando:

“Brazilian steakhouse catering for wedding”

pode ser um lead extremamente qualificado.

Da mesma forma:

BBQ restaurant

normalmente é intenção errada.

Mas:

BBQ restaurant catering

pode ser uma oportunidade.

Por isso nossa estrutura deve separar:

Negative keyword absoluta

de

keyword potencialmente relevante dependendo do contexto.

# 02. HIPÓTESE INICIAL


## Hipótese principal


O mercado não deve ser tratado simplesmente como:


> BBQ Service


O termo "BBQ" possui múltiplas interpretações nos Estados Unidos.


Pode representar:


- Restaurant
- BBQ Catering
- BBQ Food Truck
- BBQ Chef
- Grill Cleaning
- Grill Repair
- BBQ Equipment
- BBQ Recipes
- BBQ Products
- BBQ Events


Portanto, o projeto precisa estabelecer uma arquitetura semântica própria.
